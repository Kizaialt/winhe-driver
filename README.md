# AULA WIN60 HE / WIN68 HE — Монгол хэлтэй веб драйвер

Peaklab-ийн худалдаалдаг AULA WIN60 HE / WIN68 HE соронзон (Hall effect) гарыг
тохируулах веб драйверын **монгол хэлтэй хувилбар**.

Хэрэглэгч ямар нэг программ суулгах шаардлагагүй — Chrome эсвэл Edge хөтчөөр
хуудсыг нээгээд гараа USB-ээр залгаад шууд тохируулна.

> Эх драйвер: <https://hed.aulacn.com/> (AULA / 狼蛛).
> Энэ бол тухайн драйверын толь хувилбар дээр монгол орчуулга нэмсэн хувилбар.

---

## Юу нэмэгдсэн бэ

| | |
|---|---|
| `config/language.json` | `mn` локал — 343 мөр, бүрэн орчуулагдсан |
| `index.html` | Хэлний жагсаалтад `Монгол` сонголт нэмсэн |
| `js/peaklab.js` | Анхны хэлийг монгол болгох + брэндинг засвар |

Бусад 11 хэл (English, 中文, 한국어, 日本語, Deutsch, Español, ...) хэвээрээ
ажиллана. Хэрэглэгч өөр хэл сонговол сонголт нь хадгалагдана.

### `js/peaklab.js` юу хийдэг вэ

1. **Анхны хэл = монгол.** Хэрэглэгч өөр хэл сонгоогүй байвал монголоор нээгдэнэ.
   Сонгосон бол түүнийг нь хүндэтгэнэ.
2. **Брэндинг.** Эх код нь зөвхөн өөрийн домэйнууд дээр (aulacn.com, kzzi.com ...)
   AULA брэндийг тавьдаг. Бидний домэйн дээр тэр хэсэг ажиллахгүй тул гарчиг,
   мэндчилгээг гараар тавьж өгдөг.
3. **Эх кодын алдааг тойрдог.** Гар холбогдоогүй байхад хэл солиход эх код нь
   `curDevice.version` уншиж чадалгүй алдаа өгдөг (энэ нь AULA-гийн өөрийнх нь
   сайт дээр ч тохиолддог — тэнд хэл огт солигддоггүй). Бид тасалдсан хэсгийг
   нь гүйцээж өгдөг тул энд хэл солих нь **гар холбогдоогүй байсан ч ажиллана**.

Эх кодын нэг ч файлыг өөрчлөөгүй тул `tools/sync.sh` ажиллуулахад орчуулга
устахгүй.

## Локал дээр турших

```bash
node tools/serve.js
```

`http://localhost:8099` дээр нээгдэнэ. WebHID нь HTTPS эсвэл `localhost`
шаарддаг тул локал дээр ч гарыг бүрэн тохируулж турших боломжтой.

## GitHub Pages дээр байршуулах

```bash
git add -A && git commit -m "Update" && git push
```

Repo-гийн **Settings → Pages → Source: Deploy from a branch → main / (root)**.
1–2 минутын дараа `https://<хэрэглэгч>.github.io/<repo>/` дээр ажиллаж эхэлнэ.

GitHub Pages нь HTTPS өгдөг тул WebHID шууд ажиллана. `.nojekyll` файл нь
Jekyll-ийг унтраахад хэрэгтэй.

### Хэрэглэгчийн шаардлага

- **Chrome, Edge, Opera** (эсвэл өөр Chromium суурьтай хөтөч).
  Firefox болон Safari нь WebHID дэмждэггүй — тэнд ажиллахгүй.
- Гарыг **USB кабелиар** залгасан байх (2.4G/Bluetooth биш).
- Хуудас нээгдээд "Хөтчийн хандалтыг зөвшөөрөх" дарж, гарч ирэх жагсаалтаас
  төхөөрөмжөө сонгоно.

## Орчуулга засах

Бүх монгол текст ганц файлд байна: **`tools/mn.json`**.

```bash
# tools/mn.json дотор засвар хийгээд:
node tools/apply-mn.js
```

`apply-mn.js` нь `config/language.json` руу шингээж, `index.html`-ийг засна.
Дахин дахин ажиллуулж болно (idempotent).

Хэрэв AULA шинэ мөр нэмсэн бол `apply-mn.js` анхааруулаад, орчуулга байхгүй
мөрийг түр англиар үлдээнэ (хоосон үлдээвэл UI дээр хоосон харагдана).

## AULA-гийн шинэчлэлтийг татах

```bash
bash tools/sync.sh
```

Энэ нь:

1. `tools/manifest.txt` доторх бүх эх файлыг `hed.aulacn.com`-оос дахин татна
   (том файлуудыг хэмжээгээр нь шалгаад өөрчлөгдөөгүй бол алгасна).
2. Шинэ firmware байвал `config/firmware.json`-оос уншиж татна.
3. Орчуулгыг дахин шингээнэ (`apply-mn.js`).
4. `manifest.txt`-ийг шинэчилнэ.

Дараа нь:

```bash
git diff --stat      # юу өөрчлөгдсөнийг шалгах
node tools/serve.js  # туршаад
git add -A && git commit -m "Sync upstream" && git push
```

**Анхаар:** firmware шинэчлэлт орсон бол нэг гар дээр заавал туршаад дараа нь
push хийх. Хуучин firmware-тэй толь сайт нь гарыг эвдэхгүй ч, шинэ загварыг
танихгүй байх магадлалтай.

## Эрх зүйн тайлбар

Энэ бол AULA-гийн веб драйверын толь хувилбар бөгөөд Peaklab-ийн худалдаалдаг
гаруудыг монгол хэрэглэгчид ашиглахад зориулагдсан. Эх драйвер нь өөрөө
дистрибьютерүүд өөрсдийн домэйн дээр байршуулахыг **дэмжсэн** байдаг —
кодод нь `qwertykey.eu`, `kzzi.com`, `keyboard.klassegear.software`,
`silvermonkey`, `nsycagaming.com`, `storia-set-up.com` зэрэг дистрибьютерийн
домэйн бүрд тусад нь брэндинг хийдэг хэсэг бий.

Firmware болон эх код нь AULA-гийнх. Асуудал гарвал AULA-тай холбогдоно уу.
